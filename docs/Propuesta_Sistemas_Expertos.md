## **Proyecto: Sistema Web de Reservación de Canchas Deportivas** 

## **Descripción** 

El proyecto consiste en el desarrollo de un sistema web para la gestión y reservación de canchas deportivas. La plataforma permitirá a los usuarios consultar la disponibilidad de las canchas y realizar reservas en fechas y horarios específicos. Asimismo, contará con un módulo administrativo para la gestión de usuarios, canchas y reservas. 

El sistema busca optimizar el proceso de reservación, reducir conflictos de horarios y facilitar el control de las instalaciones deportivas mediante una interfaz intuitiva y accesible desde cualquier navegador web. 

## **Módulos del Sistema** 

## **1. Módulo de Autenticación** 

- Registro de usuarios. 

- Inicio y cierre de sesión. 

- Recuperación básica de contraseña (opcional). 

- Gestión de perfiles. 

## **2. Módulo de Gestión de Canchas** 

- Registro de nuevas canchas. 

- Modificación de información de las canchas. 

- Consulta de disponibilidad. 

- Cambio de estado de las canchas (disponible, ocupada o en mantenimiento). 

## **3. Módulo de Reservaciones** 

- Consulta de horarios disponibles. 

- Creación de reservas. 

- Cancelación de reservas. 

- Visualización del historial de reservas. 

- Validación para evitar conflictos de horarios. 

## **4. Módulo de Administración** 

- Gestión de usuarios. 

- Gestión de canchas. 

- Supervisión de reservas realizadas. 

- Consulta de estadísticas básicas de uso. 

## **5. Módulo de Reportes** 

- Reservas realizadas por período. 

- Canchas más utilizadas. 

- Historial de reservas por usuario. 

## **Alcance** 

El sistema permitirá administrar el proceso de reservación de canchas deportivas mediante una plataforma web con acceso para usuarios y administradores. 

Dentro del alcance del proyecto se contempla: 

- Registro e inicio de sesión de usuarios. 

- Gestión de canchas deportivas. 

- Consulta de disponibilidad de horarios. 

- Creación y cancelación de reservas. 

- Control de conflictos de horarios. 

- Administración de usuarios, canchas y reservas. 

- Generación de reportes básicos.
